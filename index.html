📘 BFS for TSP

The Travelling Salesman Problem (TSP) asks us to find the minimum-cost tour that visits every city exactly once and returns to the starting city.

BFS idea:

Start with the starting city.
Generate all possible next cities.
Store partial paths in a Queue.
Expand paths level-by-level.
When all cities are visited, return to the start.

Finally select the tour having minimum distance.
